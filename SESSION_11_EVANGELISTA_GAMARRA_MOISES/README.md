## Important rights notice

The catalogue's Public access level is not equivalent to an open licence or permission to redistribute. Before redistributing the original MTC XLSX/CSV, verify the exact ODC Attribution licence version, official URL, attribution requirements and resource scope. The source data are excluded from this repository until that verification is documented.

## Reproducibility and privacy

The repository is intended to publish researcher-authored code, documentation, provenance metadata, and outputs whose publication has been assessed as permissible. The inspected CSV schema contains no direct personal identifiers, but this is not a guarantee against all linkage or inference risks.
